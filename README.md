# Web3 Guardian

AI-powered Web3 transaction guardian. Users will later connect a Rabby-compatible wallet, review transaction risk with Gemini AI, and interact with a Solidity smart contract.

This repository currently includes the frontend foundation only.

## Project structure

```text
web3-guardian/
├── frontend/     Next.js (App Router, TypeScript, Tailwind CSS)
├── contracts/    Foundry smart contracts (coming later)
└── README.md
```

## Prerequisites

- Node.js and npm
- Foundry (for later contract work)

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
